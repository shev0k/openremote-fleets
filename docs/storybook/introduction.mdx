## What this Storybook is for

This Storybook is a developer handoff surface. It explains how the app is wired, where the main feature code lives, how data moves through real and mock mode, and which rules matter when continuing the project.

It is not meant to replace the Markdown docs. Use it when you want a quick visual overview, a codebase map, or a reminder of how feature pieces fit together.

## Main routes

The routes come from `src/app/appRoutes.ts`. Normal product pages render inside `Layout`; `Wall Display` is standalone because it is made for a TV-style operations screen.
