## Route model

`PlaybackRoute` is built from:

- route points with GPS, timestamp, speed, direction, ignition, movement, trip, GSM, GNSS, HDOP, and satellite context
- trip segments with duration, distance, stop count, max/average speed, state, markers, direction samples, telemetry samples, and graph series
- segment markers for stops, idling, driver breaks, engine-off points, offline gaps, signal degradation, and alarms

## Real mapper behavior

`openRemotePlaybackMapper.ts` is the key file. It:

- prefers `gpsLocation` history and falls back to `location`
- carries nearby telemetry samples to route points
- splits route lines around offline gaps, unless the vehicle is stationary at the same place
- splits trips using Teltonika `trip` when available
- falls back to movement evidence, displacement, ignition state, and stationary duration when `trip` is missing
- creates graph series from route points plus nearby fuel telemetry

## Shared playback UI

Shared components live in `src/app/components/playback` because Live Fleet and Route Playback both use them:

- `PlaybackTimelineDock`: play/pause, progress, speed, scrub, signal visibility, height reporting.
- `TimelineSignalRows`: mini charts for line, state, and event signals.
- `TimelineSignalSelector`: signal chips and single/multi mode.
- `TripSegmentsPanel`: trip list with active state and graph action.
- `SegmentGraphOverlay`: modal graph, signal rows, selector, and event list.
- `usePlaybackController`: requestAnimationFrame-driven playback state machine.
