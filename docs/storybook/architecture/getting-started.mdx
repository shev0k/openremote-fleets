## Install

```bash
npm install
```

## Run the app

```bash
npm run dev
```

Real mode is the default. It expects OpenRemote Manager at `https://localhost`, starts Vite on `https://localhost:5173`, and proxies `/api`, `/auth`, and `/websocket` to Manager.

```bash
npm run dev:mock
```

Mock mode uses `VITE_DATA_MODE=mock`, local fixtures, no Keycloak login, and no Manager calls.

## Run Storybook

```bash
npm run storybook
```

Storybook runs at `http://localhost:6006`. It forces mock aliases in `.storybook/main.ts`, so docs and examples can render without OpenRemote Manager.

## Verification commands

Use the smallest check that matches your change:

```bash
npm run typecheck
npm run typecheck:mock
npm run test
npm run build:storybook
npm run build:mock
npm run verify
```

`npm run verify` is the full pass. It runs tests, real and mock type checks, real and mock builds, and bundle boundary checks.

## Local rules that save time

- Keep React UI behind domain contracts.
- Do not call `manager.rest.api.*` from React components.
- Add real-mode work in `src/infrastructure/openremote`.
- Add mock fixtures and mock behavior in `src/infrastructure/repositories/mock`.
- Keep `openremote-manager/` untouched.
