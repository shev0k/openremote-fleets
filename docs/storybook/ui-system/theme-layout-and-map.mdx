## Theme tokens

The style entry is `src/styles/index.css`. It imports Tailwind setup, theme tokens, shared classes, and fonts.

The main token file is `src/styles/theme.css`. It defines semantic variables for:

- page and panel surfaces
- content colors
- borders and shadows
- brand and feedback colors
- controls
- fleet glass/acrylic surfaces
- map colors
- timeline colors
- vehicle status colors
- shadcn-compatible tokens

`@theme inline` exposes these variables to Tailwind utilities such as `bg-panel`, `text-content-primary`, `border-border-subtle`, `bg-brand`, and `bg-map-surface`.

## Display modes

The app supports three visual layers:

- light/dark through `next-themes`
- `ui-acrylic` and `ui-solid` for global surface behavior
- `live-fleet-acrylic` for stronger map/playback glass treatment

Preferences can override brand, status, map, route, and time-format settings at runtime.

## Map system

Shared map code lives in `src/app/components/map`.

Important files:

- `CustomMap.tsx`: Leaflet facade for vehicles, selected vehicle, route lines, playback route, active segment, map type, loading state, fit padding, and imperative zoom/reset/refresh methods.
- `mapTileConfig.ts`: default/satellite/terrain tile config, default Eindhoven center, and stable Leaflet options.
- `useCustomMapLayers.ts`: tile layer, vehicle markers, simple routes, and active segment polyline.
- `useCustomMapFocus.ts` and `mapFocus.ts`: initial fit, route fit keys, selected vehicle focus, bottom overlay padding, and travel animation.
- `vehicleMarkerHtml.ts`: marker and tooltip HTML.
- `routeSegments`: segmented route rendering, stop/alarm markers, and route styles.

Shared map helpers belong here when Live Fleet, Route Playback, and Wall Display can all use them.

## Storybook guidance

Storybook uses the same `src/styles/index.css` entry and mock mode aliases. Add examples when they explain a real feature or state. Avoid a standalone component showroom unless a component is truly shared enough to need API-level documentation.
